## FBC

Block A supersets in weeks 1, 3, 5, 7 and Block B in weeks 2, 4, 6, 8. Sets and rest progress from 3 × 75 s to 4 × 45 s. Pick a week and day to see the warm-up, skill primer, supersets and finisher; changes from the original program are tagged. No start date yet.
